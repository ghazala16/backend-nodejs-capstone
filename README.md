Reading: Final Project Overview (SecondChance)
In this capstone project, you'll create a back-end web application called "SecondChance". The SecondChance application connects users who wish to give away household items they no longer need with users who enjoy recycling and prefer to find free household items to match their tastes rather than purchasing new ones.
You will clone a GitHub directory containing the project's directory structure and skeleton code in respective files.

From the user interface perspective, the application contains a home page, a listings page, a navigation bar, a search function, an item details page, a registration page, a login page, and an editable profile page. The GitHub directory you clone will contain these front-end React components. You do not need to develop code for the front end.

You will write APIs and endpoints for the back end. You will use MongoDB, a NoSQL database for data storage. You will also ensure a secure authentication and login process.

At the end of the course, you will containerize and deploy the application using both the front-end provided modules and the back-end code you developed in the three prior modules. Additionally, throughout the course, you will implement some common Agile and DevOps practices as part of the full-stack developer experience.

Module 1
In the first module, you will use your GitHub account to clone the skeleton code, which will get you started with various functions and supply you with some of the code for the backend services. You will write a series of user stories to create a Kanban board to track your progress throughout the project. You will also set up a Mongo database that your application will utilize for data storage.

Module 2
In the second module, you will define API endpoints for listing resources and implement two backend services: one that allows searches with multiple parameters and another for sentiment analysis.

Module 3
In the third module, you will write APIs for the back-end services related to authentication: registration, login, and user profile functionality. You will use JSON Web Tokens as a secure means to represent the user's credentials and data.

Module 4
In the fourth module, you will containerize the entire application for deployment, including both the front-end code in addition to the back-end services you developed in the prior modules. You will use the Docker platform and apply DevOps practices, such as GitHub actions and CI/CD, to deploy your app to multiple cloud platforms, including a Kubernetes cluster and IBM code engine.

Module 5
In the fifth module,you will collect and organize all required evidence—screenshots, URLs, and outputs—from the hands-on labs for submission. Your work will be evaluated using a detailed rubric that assigns points based on completeness and correctness.

Each instructional module begins with a module overview containing further details on the services you will develop for each module.
